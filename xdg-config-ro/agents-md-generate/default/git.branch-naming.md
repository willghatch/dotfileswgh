## Branch naming

For follow-up work, continue on an existing branch when that makes sense; otherwise create a new branch.
Name a new branch `agent/DATE/FEATURE`, using the current date in `YYYY-MM-DD` form.
When branching from an existing `agent/DATE/FEATURE` branch, keep its feature path, replace its date with the current date, and append a subfeature: `agent/DATE/FEATURE/SUBFEATURE-OR-SUCH`.
