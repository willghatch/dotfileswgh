## Branch naming

For follow-up work, continue on an existing branch when that makes sense; otherwise create a new branch.
Name a new branch `agent/FEATURE/DATE`, using the current date in `YYYY-MM-DD` form.
When branching from an existing `agent/FEATURE/DATE` branch, keep its feature path, replace its date with the current date, and append a subfeature: `agent/FEATURE/SUBFEATURE-OR-SUCH/DATE`.
