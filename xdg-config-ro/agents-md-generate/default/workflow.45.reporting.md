## Reporting

If the user says `just chat`, give the full reply in chat (still use an agent-work-directory for working state).
If the user asks for a report file, write one.

Otherwise, prefer a report file if the task is complicated, the reply would exceed two short paragraphs, or the task took more than ten minutes of wall-clock time.
When writing a report file, link it in chat.
Choose just one response format: do not write a report file and then summarize it in chat.
