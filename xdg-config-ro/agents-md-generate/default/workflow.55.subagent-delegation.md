## Subagent delegation

By default, use judgment about whether and how to delegate work to subagents.
Using subagents allows for parallel work, and allows sidetrack tasks to be done without adding unnecessary data to the main agent context.
However, it also means multiple agents might do repeat work (re-reading the same info), introduces the need for coordination, etc.
Subagents are best for complicated work with highly independent or even unrelated subtasks, where different agents would have little shared context.
